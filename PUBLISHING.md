# Distribution status and remaining publication choices

The integrated v1.0 research package is at [https://github.com/metaSATOKEN/nsn](https://github.com/metaSATOKEN/nsn). All 17 evidence ZIPs plus `SHA256SUMS` are attached to the [integrated-v1.0 Release](https://github.com/metaSATOKEN/nsn/releases/tag/integrated-v1.0); filenames, byte sizes and GitHub-reported SHA-256 digests match the local manifest. GitHub's automatically generated source archives contain the repository, not those companion arrays.

**The repository remains private.** Public visibility is a separate decision for the author. Existing history and all 15 earlier version tags remain intact. [LEGACY.md](LEGACY.md) points to the exact pre-migration snapshot and the retained v0.3.12 library installer.

The PDF editions on `main` are the [integrated study](papers/nsn-integrated/NSNv2.0.pdf) and the [looped-model companion](papers/loop-kv/Loop-kv_NSN.pdf). Both covers give **info@metaclan.jp**. The [PDF inventory](metadata/pdf-status.json) records their cover identifiers, page counts, and SHA-256 hashes.

## Remaining choices

- Make the repository public when the author is ready. A private Release is not public access.
- Optionally archive the integrated edition with Zenodo and record its new DOI. The earlier DOI `10.5281/zenodo.19724817` identifies the earlier paper.

The Japanese and English integrated Markdown manuscripts are v1.0 (29 October 2026). Code uses Apache-2.0; author-owned papers, figures and data use CC BY 4.0; third-party terms are retained. The author confirmed personal self-funding, no external funding and no competing interests on 29 October 2026.

## Verification boundary

The upload preserves experimental code, results, figures, fixed plans and historical provenance. Distribution checks compare file identity and package structure; no new model calls or scientific reanalysis were performed.
